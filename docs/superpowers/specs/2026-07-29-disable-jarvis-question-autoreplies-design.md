# Отключение автоответов Джарвикса в вопросах наставникам

## Цель

Временно прекратить автоматические ответы Джарвикса в секции «Вопросы наставникам», не затрагивая ручные ответы наставников и AI-проверку домашних заданий.

## Решение

Добавить отдельный серверный флаг `JARVIS_QUESTIONS_ENABLED`.

- Автоответы разрешены только при точном значении `true`.
- При отсутствующем флаге и любом другом значении автоответы отключены.
- Проверка выполняется до ожидания задержки и перед генерацией ответа.
- Callback `/api/questions/ai-reply` при выключенном флаге принимает запрос без сохранения сообщения и возвращает признак пропуска.

Такое поведение останавливает новые задания и запоздалые ответы внешнего AI-checker. Код проверки домашних заданий и общие переменные `AI_CHECKER_URL`/`AI_CHECKER_KEY` не меняются.

## Возврат функции

Для повторного включения нужно установить `JARVIS_QUESTIONS_ENABLED=true` в окружении приложения и перезапустить или передеплоить активный контейнер.

## Проверка

- Unit-тест подтверждает, что по умолчанию автоответы выключены и включаются только точным значением `true`.
- Тест callback подтверждает отсутствие записи ответа при выключенном флаге.
- TypeScript-проверка и production-сборка должны завершиться без ошибок.
- После production-развёртывания новый тестовый вопрос не должен получить ответ Джарвикса после пяти минут.
